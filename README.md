# harness-product-design

Harness de Claude Code **separado**, especializado en UX y diseño de producto
(investigación UX · diseño de producto/UI y sistema de diseño · accesibilidad ·
producto y prototipado). Reutiliza el núcleo ARCA sin duplicarlo y sin modificar
el harness de Claude principal.

- Configuración propia: `~/.claude-product-design` (`CLAUDE_CONFIG_DIR`).
- Comando: `claude-design`.
- Instalación: `tooling/design-runtime.sh` (comprobación en solo lectura) y
  `tooling/design-runtime.sh --apply` (escribe solo los destinos del catálogo).

Estado: en construcción (F1). Plan y decisiones: vault de Adrián,
`20-ARCA/Harness-Product-Design/plan.md`.
